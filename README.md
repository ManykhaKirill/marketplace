# AnyMarket

Anymarket is a modern e-commerce web application built with a cutting-edge frontend stack and the **Next.js** App Router architecture. 

Live-demo - [AnyMarket](https://any-market.vercel.app/)


The project showcases a scalable approach to building high-performance online stores with a strong focus on developer experience and clean architecture.

---

## ⚙️ Tech Stack

- Next.js
- React
- TypeScript
- Zustand
- Tailwind CSS
- dummyjson.com API & product images

---
